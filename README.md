A little digital home for our Halloween memories. 🎃✨ Two interconnected experiences—Halloween Memories and Memory Galaxy—created to celebrate the moments, stories, and connections that made our school Halloween special.

# 🎃 Halloween Memories & Memory Galaxy

*Some stories glow for a night. Others stay with us like stars.*

A small interactive space created to preserve the memories, photographs, and little moments that made our school celebration special.

## ✨ About the Project

This project brings together two experiences:

**🎃 Halloween Memories** — A warm, playful collection of stories and memories from a special evening.

**🌌 Memory Galaxy** — An interactive universe where shared moments become stars, inviting visitors to explore and rediscover them.

Together, they offer two different ways of remembering the same night.

## 🛠️ Getting Started

Requires Node.js 24.

```bash
npm ci
npm run setup:admin
npm run dev
```

Follow the terminal instructions to configure your administrator account and start the local application.

## 🔐 Privacy & Security

The public repository is intended to contain application source code, not private student information.

Photographs, personal records, credentials, databases, and environment configuration must be excluded from the published source.

Please review the security and deployment configuration before making the application publicly accessible.

## 🎃 The Story Behind This Project

Our highschool recently held a fall celebration with a little Halloween spirit, hosted and organized by our Student Council. As the Student Council's Secretary-General, I was involved in the event alongside my friends.

While preparing for the celebration, I thought it would be fun to create something a little different—something that could make the experience more interactive and give everyone a way to revisit the memories afterward.

The idea was partly inspired by those interactive Christmas trees where people can leave messages, decorate the tree, or explore little surprises. I loved the idea of turning a shared celebration into something people could actually interact with, rather than just a collection of photographs.

So I decided to experiment with two little experiences: **Halloween Memories** and **Memory Galaxy**. One captures the warmth and playfulness of the celebration, while the other turns shared moments into a small universe of memories.

It's not a huge project, and it was never meant to be. It's simply something I wanted to make because I thought it would be fun, creative, and perhaps a little meaningful to the people who were there.

I hope you enjoy exploring it as much as I enjoyed bringing it to life. ✨

*Some stories glow for a night. Others stay with us like stars.*
